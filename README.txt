农大猫猫统计表 - 网页美化 第 2 版
================================================

一、怎么打开
------------------------------------------------
双击 index2.html 即可，不需要安装任何服务器、也不需要联网。
页面数据由 assets/js/cats-data.js 提供，图片走本地相对路径。

二、文件清单
------------------------------------------------
index2.html                       列表页
cat-detail2.html                  详情页
assets/css/style2.css             全部样式（含深色模式、响应式断点）
assets/js/main2.js                列表页逻辑（渲染、搜索、筛选、随机、动画）
assets/js/detail2.js              详情页逻辑（档案、画廊、灯箱）
assets/js/cats-data.js            猫猫数据（45 条，含图片文件名）
assets/images/cats/thumbs/        149 张 640px 缩略图（共约 17.5 MB）

三、第 2 版相对第 1 版的改动
------------------------------------------------
1. 手机端（宽度 <= 640px）网格从 2 列恢复为 3 列，封面比例由 3:4 改为 4:5，
   整页高度从 10936px 降到 5153px，减少约 52.9% 的滚动距离。
2. 随机按钮改为只在「非怀念」的猫咪中抽取，避免随机到已去世的档案。
3. 宽度 <= 420px 的超窄屏单独退回 2 列，防止名字被挤换行。

四、第 1 版以来累计的能力
------------------------------------------------
- 卡片改为图文一体：猫名压在图下沿，配渐变遮罩，不再另起一行
- 封面统一 3:4 / 4:5 竖构图，与原始照片比例匹配
- 全部图片改用 640px 缩略图（原图 60.92MB -> 17.45MB）
- 灯箱仍加载原图，保证放大后的清晰度
- 图片未加载完成时显示流光占位，加载完成后淡入
- 工具栏吸顶 + 毛玻璃
- 支持深色模式、窄屏断点、减少动效偏好
- 卡片/表格行/照片支持 Tab 聚焦，Enter 或空格触发
- 详情页照片带序号角标，灯箱显示「第几张 / 共几张」

五、已知局限
------------------------------------------------
- 深色模式的配色只做过代码层面设计，尚未在真实深色环境下逐项核对
- 桌面大屏（>= 1400px）的四列布局尚未截图验证
- 未做自动化测试，仅通过浏览器实测关键交互
